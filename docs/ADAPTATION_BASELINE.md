# YYB 脚本适配基线

基线日期：2026-09-04

本目录当前基线包含 batch-01 至 batch-06 共 29 个适配脚本，以及共享运行辅助文件 `tools/env.js`。

本版确定规则：

- 仅替换原脚本依赖的旧微信服务接入层，保留原业务接口、字段、签名和任务流程。
- YYB 账号使用 `服务器地址@账号ID或OpenID`，多账号支持换行或 `&`。
- 本地缓存按规范化后的 `server@ref` 隔离。
- 原脚本已有的 JSON、手动 token、旧变量和回退方式继续保留。
- 统一保留日志收集、运行耗时和青龙 `sendNotify` 能力。
- 手机号数据使用 `/wxapp/getPhoneNumber`，普通用户信息不得代替手机号授权。
- 缺少真实 `operateWxData` payload 时不得猜测或编造。

本版只代表静态审查和语法检查基线。没有真实连接 YYB 与各目标业务服务的脚本，不能据此认定已经完成线上联调。
